Import Anki decks into FlashLock

File import makes a separate FlashLock copy. It does not sync edits, review history or scheduling back to Anki. Use it to bring familiar cards into short study breaks before Android apps.

1. Export one deck

In Anki, export the deck as an Anki Deck Package (.apkg). Include media if it uses pictures, then save the file on your Android phone. Start with a small deck to check compatibility.

An .apkg normally contains a deck; .colpkg is a whole-collection backup. For this workflow, export the single deck you want rather than renaming a collection backup. See Anki’s export instructions.

2. Choose the file in FlashLock

  1. From Home, open New Deck and choose the file-import option. It may be labelled Upload a deck in your version.
  2. Tap Choose deck file and select the .apkg in Android’s file picker. Wait for the review screen.
  3. Check the questions, answers, images and any import notice. If needed, Review imported cards reopens the preview.
  4. Enter a deck name and choose Finish deck and go home to save. Select that deck for your learning breaks.

If your version also offers an AnkiDroid connection, that is a different route. These steps describe importing a file, not linking a live collection.

What to check before saving

  • Cards: templates and cloze questions can be converted, but complex layouts may be simplified. Check both sides.
  • Images: the file-import path supports embedded PNG, JPEG, WebP and GIF as still images. Remote images and SVG are not loaded; missing images may show [Image unavailable].
  • Other media: do not assume audio, video or interactive Anki styling carries into the local-copy workflow. Check the preview and your installed version’s import notice.
  • Progress: imported cards start with FlashLock’s own review state. Keep using Anki separately if you need its existing schedule.

If the import fails

  • Wrong file: .apk is an Android installer, not an Anki deck. Use .apkg; CSV and JSON are separate supported card-file choices.
  • File will not open: finish downloading it, save a local copy in Downloads, then choose it again. Re-export a single deck if necessary.
  • Newer export format: if Anki offers Support older Anki versions, try that export option. It changes the package format; it does not guarantee every template will work.
  • Size-limit error: split a large deck or reduce oversized images. Compressed file size is not the same as the unpacked database and media size.
  • Generic storage message: “couldn’t finish importing” alone does not establish that storage is full. If it repeats, send support your app version, file type and exact error.
