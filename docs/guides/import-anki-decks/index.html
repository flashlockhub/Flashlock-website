Import Anki decks into FlashLock

An Anki deck package is a file ending in .apkg. FlashLock reads that file to create cards you review inside FlashLock. This is a separate local import, not native AnkiDroid sync: Anki review history and scheduling are not carried over, and reviews in FlashLock do not update Anki.

Prepare a small deck first

In Anki, export the deck as an Anki Deck Package (.apkg) and make the file available on your Android phone. Include its media if you need embedded images. Keep your original deck as a backup. Use cards you own or have permission to copy. You do not need AnkiDroid installed for this file-import workflow.

FlashLock is an Android beta: Google Play eligibility applies and access may be limited. The steps below describe the current regular build; your installed beta may be older.

Import, check and save

  1. On FlashLock’s Home screen, tap New Deck. On Create a deck, choose Upload a deck.
  2. Tap Choose deck file and select your .apkg file using Android’s file picker. Wait while FlashLock reads the file and prepares the cards.
  3. The review screen opens when the import is ready. If you return to the import screen, Review imported cards opens it again. Check the fronts, answers and any import notice, especially for complex cards.
  4. Enter a Deck name, then tap Finish deck and go home. The new deck is saved only when you finish reviewing it. Use Finish deck and create more if you want to add another deck afterwards.

What carries across?

The importer handles Anki card templates and cloze deletions (fill-in-the-blank cards), but it is not a full Anki renderer. Unsupported templates may be simplified; check the result rather than assuming an identical layout. Imported cards start with FlashLock’s own review state.

Embedded PNG, JPEG, WebP and GIF images are supported as static images and saved privately on the device. Animated images become still images. Remote images and SVG are not loaded; missing or unsupported images can show [Image unavailable]. Do not rely on imported audio, video, scripts or complex interactive styling. Test a small representative deck before importing a large collection.

Troubleshooting

Wrong file? An .apk installs an Android app; it is not an Anki deck. Choose .apkg, not .apk. FlashLock also accepts CSV and JSON card files.

Cannot open or incomplete file? Save it to Downloads and retry, or export the .apkg again. For a size-limit error, split the deck: the importer caps a deck at 10,000 cards and also limits archive, collection and image sizes. Fewer cards alone do not guarantee that a media-heavy file will fit.

Cards look different? Read the import notice and inspect questions and answers before finishing. Keep using Anki for material that depends on unsupported rendering or media. Next, set up flashcards before apps.
