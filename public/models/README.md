# Flashcard geometry

Generated for FlashLock using Zoo Zookeeper through `GET /ws/ml/copilot` (Zoo CLI `ml kcl copilot`), 9 October 2026. Accepted generated KCL is `flashcard.kcl`.

Exported with Zoo CLI v0.2.203:
`zoo kcl export --output-format glb --deterministic main.kcl export`

85 × 120 × 1.5 mm rounded card, 6 mm face-corner radii, plain faces. No edge chamfer in the accepted model. GLB uses metres, CAD XY face exported into glTF XZ. Browser rotates it into display coordinates, scales to fit the demo, adds materials and accessible HTML front/back labels, and animates around the vertical axis.

The site serves this file locally. No Zoo account, credentials or network connection to Zoo is required by visitors. If WebGL/model loading is unavailable, the same interaction uses a CSS front/back fallback. Reduced-motion users see an immediate reveal.
