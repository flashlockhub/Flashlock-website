Which fits your Anki routine?

Choose AnkiBlock if you want to keep reviewing in AnkiDroid. Its smaller goal releases one app; completing the daily goal releases the blocked set. Choose FlashLock if you want the review itself inside a short app-opening break, using cards you create or import.

Importing is not connecting.

An Anki file import makes a local FlashLock copy. Reviewing that copy does not update the original Anki collection. If you want to keep your review history in Anki, make that distinction before choosing a route. See the Anki import guide.
