Quick questions.

Can I use my own cards?+

Yes. Make your own, import Anki cards, or pick a ready-made deck.

Do I choose when breaks start?+

Yes. Pick the apps, set when breaks start, and choose how many cards to do.

Does it work on my phone?+

FlashLock is for Android 8.0 and up. Join the beta on Google Play, then install the app. There’s no iPhone app yet.
